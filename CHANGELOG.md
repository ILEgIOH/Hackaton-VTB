# Изменения

## Спринт 2 — данные, безопасность, масштабирование

**Безопасность и комплаенс**
- Журнал аудита: входы, отказы в доступе, оценки, решения, выгрузки, настройки. Записи связаны цепочкой SHA-256,
  проверка целостности — одной кнопкой (`journal.py`, экран «Безопасность и аудит»).
- Подпись пакетов агента HMAC-SHA256: ключ не передаётся по сети, окно ±5 минут, защита от повтора, журнал отказов.
- Закрытый контур (`CC_ONPREM=1`): ИИ и почта только на внутренних адресах. Внешние шрифты из интерфейса убраны.
- Обезличивание данных для ИИ: без названия заёмщика, номера договора и реальных серийных номеров.
- Маскирование свободного текста перед нейросетью: реквизиты сделки → метки, серийные номера → псевдонимы, почты, телефоны,
  карты, СНИЛС, паспорта, счета, ИНН → вырезаются; в ответе реквизиты восстанавливаются, в журнал пишется только счётчик.
- ИИ только дополняет правила: замечания правил нельзя убрать или ослабить, находки модели — отдельным блоком «Дополнительно от ИИ».
- Проверка ИНН по перечню (115-ФЗ): сделка останавливается до проверки комплаенсом.
- Заголовки безопасности (CSP, X-Frame-Options, Referrer-Policy), проверка Origin, `Secure`-cookie за TLS.

**Автоматизация**
- Плановая переоценка по 590-П: оценки старше 90 дней обновляются автоматически, прежняя сохраняется в документах.
- История телеметрии в SQLite с автоматическим удалением по сроку хранения.

**Масштабирование и эксплуатация**
- Отложенная запись состояния: приём телеметрии ×2,7 (≈1 450 пакетов/с на один экземпляр).
- `/api/health`, `/api/metrics` (Prometheus), Dockerfile, `deploy/docker-compose.yml` с локальной моделью ИИ.
- Воспроизводимые замеры `tools/bench.py`, CI на GitHub Actions (тесты на Python 3.10 и 3.12).
- Описание API для интеграции: `docs/openapi.yaml`.

**Документы:** `docs/SECURITY_COMPLIANCE.md`, `docs/ARCHITECTURE.md`, `docs/PILOT_PLAN.md`.

**Тесты:** 42 → 63.
